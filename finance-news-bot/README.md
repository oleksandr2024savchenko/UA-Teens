# 📈 Finance News Bot — новини з поясненнями

Telegram-бот, який цілодобово збирає новини **лише з перевірених джерел**, відбирає найважливіше (з особливою увагою до фінансів) і **пояснює українською з англійськими термінами**: що сталося, що означають терміни, як це вплине на ринки, долар, гривню і твій гаманець.

> Приклад: виходить новина про ставку ФРС → бот надсилає картку: що вирішив Fed, що таке *Fed funds rate* простими словами, як це вплине на S&P 500, долар, золото, біткоїн і гривню, що буде далі і за чим стежити. Кнопка **🧠 Глибше** дає механізм, аналогію, історичний контекст і сценарії, а **❓ Запитати** відповідає на твої запитання саме про цю новину.

## ✨ Можливості

| | |
|---|---|
| 📰 **Стрічка** | Свіжі новини з фільтрами: усі / 💰 фінанси / 🇺🇦 Україна / 🌍 світ, з пагінацією |
| 🔥 **Головне** | Топ-8 подій доби за важливістю |
| 🧠 **Розбір кожної новини** | Суть · що сталося · чому важливо · терміни простими словами · вплив на ринки (▲▼) · для України · що далі · за чим стежити |
| 🔔 **Сповіщення** | Бот сам надсилає важливі новини. Поріг важливості й теми налаштовуються |
| 🗞 **Дайджест** | Щодня в обраний час: головне за добу + настрій ринків |
| 📊 **Ринки** | S&P 500, Nasdaq, Dow, VIX, 10Y yield, DXY, EUR/USD, золото, Brent, BTC/ETH/SOL, курс НБУ + 🤖 «Що рухає ринки?» |
| 📚 **Словник** | 20 ключових термінів одним натиском або `/term будь-що` |
| 💬 **Вільні запитання** | Просто напиши: «чому падає біткоїн?» — бот відповість з урахуванням свіжих новин і пам'ятає контекст розмови |

### Як працює конвеєр

```
кожні 10 хв:  RSS 30 джерел ──► дедуплікація (URL + заголовок)
                                   │
                                   ▼
               Claude: відбір шуму, групування однієї події з різних видань,
               оцінка важливості (1–10) та «фінансовості» (0–10), категорія
                                   │
                                   ▼
               Claude: повний розбір для важливих (≥ 6/10), фінанси в пріоритеті
               (бере текст статті, якщо він не за пейволом)
                                   │
                                   ▼
               розсилка підписникам за їхнім порогом і темами (≤ 3 за цикл)
```

Менш важливі новини теж потрапляють у стрічку — розбір для них генерується на льоту, коли натиснеш **🧠 Пояснити**. Усі розбори кешуються.

## ✅ Джерела

Тільки перевірені: **офіційні** (Federal Reserve, ECB, IMF), **топ-медіа** (Bloomberg, WSJ, MarketWatch, CNBC, Financial Times, The Economist, BBC, The Guardian, NPR, DW), **українські** (Економічна правда, Інтерфакс-Україна, Укрінформ, Суспільне, Українська правда, Kyiv Independent, Forbes Україна), **профільні** (Yahoo Finance, CoinDesk, Ars Technica, TechCrunch). Жодних анонімних телеграм-каналів.

Повний список із URL — у [`src/sources.js`](src/sources.js). Свої джерела можна додати у `data/sources.json`:

```json
[{ "id": "nbu", "name": "НБУ", "url": "https://…/rss", "tier": 1, "focus": "finance", "lang": "uk" }]
```

Вимкнути джерело: `DISABLED_SOURCES=yahoo_finance,techcrunch`. Стан усіх джерел — команда `/health` (для адмінів).

## 🚀 Запуск

### 1. Отримай ключі
1. **Telegram:** напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопіюй токен.
2. **Claude API:** [console.anthropic.com](https://console.anthropic.com/) → API Keys.
3. **Свій Telegram ID** (для адмін-команд): напиши [@userinfobot](https://t.me/userinfobot).

### 2. Налаштуй
```bash
cd finance-news-bot
cp .env.example .env
# заповни TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY, ADMIN_IDS
```

### 3a. Запуск через Docker (рекомендовано для сервера)
```bash
docker compose up -d --build
docker compose logs -f
```

### 3b. Або напряму (потрібен Node.js ≥ 22.13)
```bash
npm install
npm start
```

Після запуску відкрий бота в Telegram і натисни **Start**. Перший цикл збирає новини «тихо» (без розсилки старого), далі все працює автоматично.

Дані зберігаються в SQLite (`data/bot.db`) — переживають перезапуски. Старі новини автоматично чистяться через 14 днів.

## ⚙️ Налаштування (`.env`)

| Змінна | За замовчуванням | Що робить |
|---|---|---|
| `CLAUDE_MODEL` | `claude-opus-5-5` | Модель для розборів і відповідей |
| `CLAUDE_TRIAGE_MODEL` | як `CLAUDE_MODEL` | Модель для відбору новин (найчастіший виклик). Щоб заощадити — постав `claude-haiku-5-5` |
| `FETCH_INTERVAL_MIN` | `10` | Як часто перевіряти джерела |
| `ANALYZE_MIN_IMPORTANCE` | `6` | З якої важливості розбирати новину одразу |
| `MAX_ANALYSES_PER_CYCLE` | `6` | Ліміт розборів за цикл (контроль витрат) |
| `TIMEZONE` | `Europe/Kyiv` | Для дайджестів |
| `ADMIN_IDS` | — | ID адмінів: `/stats`, `/refresh`, `/health` |

**Про витрати:** один цикл = 1 запит на відбір (лише якщо з'явилися нові статті) + до 6 розборів. Кожен користувач має ліміт 25 AI-запитів на годину. Розбори, терміни словника, дайджест і коментар ринку кешуються, тож 100 людей, які відкрили ту саму новину, — це один запит до Claude.

## 🗂 Структура

```
src/
  index.js     — запуск, планувальник циклів і дайджестів
  config.js    — змінні середовища
  sources.js   — перевірені джерела
  fetcher.js   — збір RSS, нормалізація, дедуплікація, витяг тексту статті
  ai.js        — Claude: відбір, розбір, «глибше», Q&A, словник, дайджест, коментар ринку
  pipeline.js  — конвеєр збір → відбір → розбір → розсилка
  markets.js   — котирування (Yahoo Finance, CoinGecko, НБУ)
  format.js    — красиві картки в Telegram HTML
  bot.js       — інтерфейс: меню, кнопки, налаштування, розсилка
  db.js        — SQLite (вбудований node:sqlite, без нативних залежностей)
```
